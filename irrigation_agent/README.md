# Irrigation Agent

Owns irrigation-related updates for farmers, pump operators, canal users, and
water committees: water turns, crop-stage scheduling, pump safety, and
conservation.

The agent now asks for irrigation method and crop stage, then generates a more
practical daily message with water-use guidance based on the selected crop and
source. This keeps the advice specific to field conditions and less generic.

Keep local canal schedules and water-authority integrations in this module.
